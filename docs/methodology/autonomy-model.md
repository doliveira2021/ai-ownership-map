# AI Autonomy Model

## Purpose

The autonomy model measures how much authority AI has to influence or execute business actions.

## Levels

| Level | Name | Description |
|---|---|---|
| 0 | No AI | No meaningful AI use in the assessed scope. |
| 1 | Generative | AI creates or summarizes content but does not directly influence actions. |
| 2 | Advisory | AI provides recommendations or decision support to humans. |
| 3 | Workflow Initiation | AI can initiate workflows, but material actions require human approval. |
| 4 | Action Execution | AI can invoke tools, APIs or applications and execute business actions. |
| 5 | Autonomous Operations | AI can reason, select tools and execute multi-step actions across systems with limited human intervention. |

## Why autonomy matters

The same control gap should not generate the same priority in a low-autonomy assistant and a privileged autonomous agent. Autonomy therefore acts as a prioritization modifier.

## Additional dimensions

Autonomy should be interpreted alongside:

- privilege
- data sensitivity
- ability to cause external side effects
- reversibility of actions
- human oversight
- transaction/action limits
- agent-to-agent delegation
